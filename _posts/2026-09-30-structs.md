## 1. 结构体的声明

### 1.1 结构体概念

结构体的成员可以是**不同类型的变量**。

### 1.2 结构体特殊声明

**匿名结构体类型**创建的同时就必须创建变量。

### 1.3 结构体的自引用

正确的自引用方式：结构体成员中**包含下个结构体节点的地址**（指针），而不是直接包含自身类型的成员。

## 2. 结构体内存对齐

结构体在存储的时候会有**对齐**现象。

`offsetof` —— 宏 `offsetof(type, member)`：

```c
#include <stddef.h>
```

可以计算结构体成员起始位置相较于结构体起始位置的**偏移量**。

### 2.1 对齐规则

- 结构体的**第一个成员**永远放到偏移量为 `0` 的地址处
- 其他成员变量要对齐到某个数字（**对齐数**）的整数倍地址处

![对齐数的定义：编译器默认对齐数与成员大小的较小值，VS 默认为 8，Linux gcc 无默认对齐数]({{ site.baseurl }}/assets/posts/structs/img02.jpg)

- 结构体**总大小**是**最大对齐数**的整数倍
- 若嵌套了结构体：嵌套结构体成员对齐到**自己成员中最大对齐数**的整数倍处，结构体的整体大小就是所有最大对齐数（含嵌套结构体中成员的对齐数）的整数倍

![嵌套结构体的对齐练习：sizeof 计算与内存布局]({{ site.baseurl }}/assets/posts/structs/img03.jpg)

### 2.2 为什么存在内存对齐

- **平台原因：** 不是所有硬件平台都能访问任意地址上的任意数据，某些硬件平台只能在某些地址处取某些特定类型的数据，否则抛出硬件异常
- **性能原因：** 数据结构（尤其是栈）应尽可能在**自然边界**上对齐

### 2.3 修改默认对齐数

```c
#pragma pack(对齐数)

struct s
{
};

#pragma pack()
```

## 4. 结构体实现位段

### 4.1 什么是位段

- 位段的成员必须是 `int`、`unsigned int`、`signed int`
- 位段的成员名后有一个**冒号和一个数字**
- 位段是**不跨平台**的

### 4.2 位段的内存分配

- 成员可以是 `int`、`unsigned int`、`signed int`
- 以 4 个字节（int）或 1 个字节（char）的方式开辟

### 4.3 位段的应用

可节省**网络传输数据报**的空间。

### 4.4 位段使用的注意事项

位段的成员**不能取地址**，所以不能对位段成员使用 `scanf`，要先赋值给普通变量再放回位段。
