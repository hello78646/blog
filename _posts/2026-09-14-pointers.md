## 二、深入理解指针 2

### 1. const 修饰指针

#### 1.1 const 修饰变量

常变量是变量，但具有常属性，不能改。

```c
const int n = 10;
```

C 语言中这里的 `n` 是**常变量**；但如果是 C++ 中，这里的 `n` 就是**常量**。

目的：改变 `n` 的值。用指针变量 `p` 可以改 `n`，但会有警告（破坏了 const 的本意）。

const 位置三种情况：

- ① **const 放在 `*` 左边**：限制的是指针变量**指向的内容**，不能通过 `*p` 赋值来改变 `*p` 的内容（即 `n`）。但是 `p` 的内容（地址）可改，`p` 可以指向其他变量（如 `m`）
- ② **const 放在 `*` 右边**：反之，`p` 不能改，但 `*p` 能改
- ③ **如果 `*` 两边都放 const**：则都不能改

### 2. 野指针

#### 2.1 野指针成因

- **不初始化**：随便找地址放入信息，导致非法访问
- **指针越界访问**：指针指向的范围超出数组范围
- **指向的空间释放后，信息已销毁**，指针仍存着旧地址

#### 2.2 如何规避野指针

##### 2.2.1 指针初始化
- 如果知道指针指向哪，就直接赋值
- 如果不知道指针指向哪，就初始化为 `NULL`（`NULL` 的地址是 0，指针不会去访问）

```c
int *p = NULL;
```

##### 2.2.2 小心指针越界
##### 2.2.3 指针变量不使用时应及时置 NULL，使用前检查有效性
##### 2.2.4 避免返回局部变量的地址

```c
{
    ...
    return &n;  // 局部变量地址，函数结束就失效，不能返回
}
```

### 3. assert 断言

```c
#include <assert.h>
assert(p != NULL);
```

`assert(p != NULL)`：验证变量 `p` 是否等于 `NULL`。若（不等于）为真，程序继续；若（等于）为假，就会报错。

想关掉多条 assert 语句：在 `#include` 声明前加 `#define NDEBUG`。

## 三、深入理解指针 3

### 1. 数组名的理解

大部分情况，数组名就是数组**首元素**的地址。例外有两个：

- `sizeof(arr)`：这里的 `arr`（数组名）代表的是整个数组
- `&数组名`：这里的 `arr` 取出的是整个数组的地址；`&arr + 1` 从第一个地址跳过整个数组

### 2. 使用指针访问数组

`arr = p = 起始地址`：

```c
*(p + i) == p[i] == *(arr + i)
```

实际上，用数组下标的形式访问数组元素时，编译器在处理时还是转换成**指针的形式**来处理：

```c
arr[i]  ——>  *(arr + i)
```

### 3. 一维数组传参的本质

- 本质上还是**传址**（传的是数组首元素的地址）
- 函数内部不能正确获得实参数组的个数，所以函数内部求不出数组的元素个数（`sizeof(arr) = 8`）

### 4. 冒泡排序

- 核心思想：**两两相邻的元素进行比较**，一趟确定一个最大/最小值，多趟排完。

### 2. 数组指针变量

#### 2.1 数组指针变量是什么？

存放数组的地址（`&arr`），指向的就是数组。

```c
int arr[5];
int (*p)[5] = &arr;
*p == *&arr == arr
```

拆解 `int (*p)[5]`：

- 去掉名字后 `(*p)` 剩下的就是类型
- `[5]`：`p` 指向数组的元素个数
- `int`：`p` 指向数组的元素类型
- `p`：变量名

```c
int arr[] = { 0 };
int *p = arr;
p[i] == *(p + i) == arr[i]
```

### 3. 二维数组传参的本质

数组指针一般在二维数组传参的时候才会用。二维数组传参本质上也是传递了**地址**——传递的是**第一行这个一维数组的地址**。

## 六、深入理解指针 6

### 1. sizeof 和 strlen 的对比

| | sizeof | strlen |
|---|---|---|
| 计算内容 | 计算变量**所占内存的大小** | 从某地址得到的元素开始，向后统计到 `\0` 前的**字符个数** |
| 对数组 `arr` | `sizeof(arr)`，这里的 `arr` 代表整个数组，计算的是整个数组的大小 | `strlen(arr[0])` 数组首元素 ASCII 值传给 strlen 函数，该值会被当作地址，形成**非法访问** |

- `&arr`：这里的数组名代表整个数组，取出的是整个数组的地址；`&arr + 1` 跳过一个数组空间
- `*&arr`：这里解引用访问到整个数组空间
