## 1. 整数在内存中的存储

**整数的二进制表示方法有三种：原码、反码、补码。**

有符号整数的三种表示方法，都有**符号位**和**数值位**两部分：

- `0` —— 正
- `1` —— 负
- 最高位的一位是符号位，剩余的都是数值位

- **正整数**的原码、反码、补码都相同
- **负整数**的三种表示方法各不相同

> 对整型来说：**数据存放进内存中，其实存放的是二进制的补码。**

## 2. 大小端字节序和字节序判断

- **小端字节序存储：** 一个数据的**低位**字节存储到**低地址**处，**高位**字节存储到**高地址**处
- **大端字节序存储：** 一个数据的**低位**字节存储到**高地址**处，**高位**字节存储到**低地址**处

取值范围（char）：

- `signed char` 内存取值范围：`-128 ~ 127`
- `unsigned char` 的取值范围：`0 ~ 255`

**死循环的坑：** `-1` 的补码是 32 个 1，但被当作**无符号整数**打印出来是 42 亿多，因此打印陷入死循环。

## 3. 浮点数在内存中的存储

### 3.1 浮点数的存储

根据国际标准 **IEEE 754**（电气和电子工程师协会），任意一个二进制浮点数 `V` 可以表示成下面的形式：

```
V = (-1)^S × M × 2^E
```

- `(-1)^S` 表示**符号位**：当 `S = 0` 时，`V` 为正数；当 `S = 1` 时，`V` 为负数
- `M` 表示**有效数字**：`M >= 1`，`M < 2`
- `2^E` 表示**指数位**

#### 3.1.1 浮点数存的过程

所以将 `S`、`M`、`E` 存储，就相当于存储了浮点数。

- 对于 `M`：如 `1.01`，因为二进制中个位只能是 1，所以**只存 `01`**，提高一位精度
- 对于 `E`：它是无符号整数（非负）：
  - 若是 8 位，则取值范围是 `0 ~ 255`
  - 若是 11 位，则取值范围是 `0 ~ 2047`
- 但像 `0.5` 这样：`(-1)^0 × 1 × 2^(-1)` 里 `S` 是 0，`M` 是 1，`E` 是 `-1`
- **所以规定：** 存入内存时，`E` 的真实值必须加上一个**"中间数"**（8 位的 `E`：127；11 位的 `E`：1023）后，才是 `E` 的存储值

**存入顺序：`S` `E` `M`** —— 例：

```
0 [10000001] 0110000000000000000000
```

#### 3.1.2 浮点数取的过程

`E` 从内存中取出，还可以再分 3 种情况：

- ① **E 存储值不为全 0 也不为全 1**：原路返回
- ② **E 存储值为全 0**：则 `E = 1 - 127` 或 `E = 1 - 1023`，这样才能表示接近于 0 的数字
- ③ **E 存储值为全 1**：则 `E = 255 - 127`、`E = [11111111111](二进制) - 1023`，则表示无穷
